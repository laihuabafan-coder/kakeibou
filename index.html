GitHub Pages で無料公開する手順

  1. GitHubで新しいリポジトリ（例: my-kakeibo）を作成します。
  2. このHTMLファイルを index.html という名前で保存して、リポジトリにコミット・プッシュします。
  3. リポジトリの Settings > Pages を開きます。
  4. Branch を main (または master) の / (root) に設定し、Save をクリックします。
  5. 数分で https://<your-username>.github.io/my-kakeibo/ で家計簿アプリが世界公開されます！
